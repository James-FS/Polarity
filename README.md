# 极性失控（Polarity Unleashed）

一款以磁力和极性传播为核心的 2D 俯视角解谜游戏。给敌人和箱子赋予正负极性，利用吸引、排斥、碰撞与场景机关，在有限的标记次数内清除每关的敌人。

## 玩法特色

- 正负极相吸，同极相斥；磁力会影响敌人、箱子和炮弹的运动。
- 带极性的敌人或箱子接触无极性对象时，可以免费传播极性。
- 通过改变站位和标记时机，引导敌人撞向彼此、炮弹或尖刺。
- 六个逐步引入机制的关卡，每关都有独立的极性标记预算。

## 操作

| 输入 | 操作 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 指向可标记的敌人或箱子 |
| 鼠标左键 | 赋予正极或切换为正极 |
| 鼠标右键 | 赋予负极或切换为负极 |
| 按住空格 | 慢速瞄准，松开后恢复正常速度 |
| R | 重试当前关卡 |
| Esc | 暂停或恢复 |

## 运行源码工程

本仓库包含团结引擎工程。使用团结引擎 **1.10.1** 打开仓库中的 `Polarity/` 文件夹，然后从主菜单场景运行游戏：

```text
Polarity/Assets/Polarity/Scenes/MainMenu.scene
```
