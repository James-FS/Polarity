# 实验室墙体模块

这组 PNG 是根据 `Arts/墙壁概念/` 的设计稿生成的独立透明精灵，当前仅存放在美术目录，尚未导入游戏。

## 文件

| 文件 | 用途 |
| --- | --- |
| `Wall_Far_Straight.png` | 远侧普通直墙，可水平重复 |
| `Wall_Far_Light.png` | 远侧嵌灯直墙，与普通直墙交替 |
| `Wall_Front_Straight.png` | 近侧前景直墙，可水平重复 |
| `Wall_Left_Straight.png` | 左侧直墙，可垂直重复 |
| `Wall_Right_Straight.png` | 右侧直墙，可垂直重复 |
| `Wall_End_Right.png` | 横墙右端帽；左端可对同一精灵水平翻转 |
| `Wall_Corner_Post.png` | 覆盖横墙与竖墙交接处的角柱 |

## 尺度与拼接

- 全部文件都是 `1254 × 1254`、带真实 Alpha 通道的 PNG。若一个画布代表 2 个世界单位，导入时 Pixels Per Unit 设为 `627`，变换缩放保持 `1`。
- 横墙的中心线位于画布水平中线；相邻横墙的中心点相距 2 个世界单位。远墙普通版与嵌灯版两侧的不透明区均为 y=458–795，可交替放置。前景直墙自身两侧为 y=465–789，应单独成排使用。
- 侧墙的中心线位于画布竖直中线；相邻侧墙的中心点相距 2 个世界单位。上下接口仅有约 1 像素的 Alpha 差异。
- 右端帽的左接口与远墙约差 1 像素；放在直墙末端时可轻微重叠以隐藏抗锯齿边缘。左端使用 `flipX`。
- 转角采用**叠放结构**：让横墙与竖墙在角部相交，`Wall_Corner_Post.png` 放在二者上方盖住接缝。角柱不是替换直墙末端的 L 形硬拼块。

这些素材只包含视觉，不带碰撞体。接入游戏时应沿用现有 `Wall` 层、墙体碰撞体与前景遮挡引用，并在实际视口检查接头、排序和角色遮挡。

## 生成说明

使用内置 ImageGen 生成。共同提示：以墙体概念图为画风参考，绘制正交俯视的蓝灰色实验室金属墙；浅钢色顶盖、深蓝立面、左上方高光、轻微磨损；`1254 × 1254` 正方形透明画布，画布外区域保持真实 Alpha。各图分别指定普通远墙、嵌灯远墙、前景墙、左右侧墙、右端帽和覆盖交接处的独立角柱。普通远墙与嵌灯版保持相同两端截面。
