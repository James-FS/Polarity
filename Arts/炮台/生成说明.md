# 实验室防卫炮台 / v1 / 2026-10-17

用户批准概念：`炮台-批准概念-v1.png`。以imagegen从该概念生成透明素材，保留米白装甲、深灰金属固定座、螺栓、通风栅、少量黄黑警示及蓝色能源炮口。

游戏图集：`../../Polarity/Assets/Polarity/Art/Turret/TurretAtlas-v1.png`，原图1254×1254、透明背景。由TextureImporter按真实透明轮廓切分九个Sprite：Base，以及Head_E、Head_NE、Head_N、Head_NW、Head_W、Head_SW、Head_S、Head_SE。生成排布并非精确等宽网格，不要直接改回均匀切片；素材边界已检查没有裁边。

PPU=250，关闭mipmap和CPU可读副本、使用Bilinear与无压缩。各炮头自定义pivot按炮口蓝光中心校准，无可见蓝光的北向按炮管末端校准，使末端在对应方向距轴1.1D；底座pivot在旋转轴承中心，底座缩放0.83。切片和pivot保存在PNG的Unity meta中，后续更换图片时须一同重新校准，不能仅按图片几何中心旋转。

TurretView按实际瞄准方向选择八方向素材，仅对扇区内剩余角度做连续旋转，保持底座固定。原Base/Top/Barrel对象及组件保留，旧Top渲染禁用，避免破坏关卡已有引用。射击、碰撞和炮弹规则不在此资源中调整。

炮台素材接入与实际运行的历史摘要见`../../docs/实施记录.md`。
