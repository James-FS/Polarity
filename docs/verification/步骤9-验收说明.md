# 步骤 9：炮台与默认负极炮弹验收

2026-10-10，团结 1.10.1 / 2022.3.62t13，实际工程 `D:\Code\Polarity\Polarity`，Codely Unity Bridge 1.0.86。

## 交付与运行

Game 沿用六敌人、负极箱子、玩家与通道，增加一个位于 (6, 2.7) 的 Turret Prefab。炮台 Static、不可摧毁，无 PolarityBody/Health；预警方向线和独立炮管读取模拟状态。首次冷却 1.5 秒，预警约 1 秒，其中末段 0.2 秒锁定，射击间隔约 3.5 秒。炮弹半径 0.3、质量 0.3、初速 5、寿命 6 模拟秒，Dynamic/Continuous，安全限速沿用 12。炮口偏移 1.1；出生占地检测被实体阻挡时跳过本次射击，不越过掩体生成。

World 顺序为标记 → 炮台与注册 → 快照 → 移动/磁力 → 一次 Simulate → 接触合并 → 伤害与消耗 → 传播 → 注销/销毁 → 胜负与通知。ProjectileCollection 合并双边回调和持续接触，以距本步起点最近的接触选一次命中；近似等距时掩体优先，再按角色稳定 ID。炮弹只向统一伤害集合提交直接命中，不走碰撞速度阈值；沿用目标全局冷却，每枚命中即消费，即使目标处于无敌状态。消耗立即使 PolarityBody 无效，传播后才改注册列表。
