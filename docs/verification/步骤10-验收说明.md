2026-10-11，团结 1.10.1 / 2022.3.62t13，工程 `D:\Code\Polarity\Polarity`，Codely Unity Bridge 1.0.86。

## 交付

新增 HUDView 与 HUD Prefab，复用 Game.scene、现有 EventSystem、五种 Actor Prefab 和候选轮廓。界面显示生命、活动敌人数、标记预算、操作说明、倍率、主动标记结果及实际传播来源/目标；预算耗尽仍提示移动与重试。暂停界面提供操作说明、传播规则表、恢复和重试；胜负界面只重试当前房间，多关入口留步骤 11。

LevelController 在 Update 采样 Space、Esc、R，按钮也提交到同一流程入口。SimulationWorld 唯一管理 timeScale：运行 1 或 0.3，暂停 0，重试恢复 1。fixedDeltaTime 始终 0.02，不给力、物理步或规则计时再乘倍率。暂停中继续记录空格当前状态，恢复时使用当前倍率；重试后的空格必须先释放，再按下才进入慢速。R 优先于同帧慢速/暂停。

HUD 初始化先读事实，再订阅标记、传播、生命、预算、敌人数、阶段与倍率事件；禁用时取消订阅及按钮监听。标记输入在查询目标前直接检测当前坐标的 UI，暂停/终局面板立即拦截全屏，不依赖上一帧 EventSystem 或 Canvas 重建。World 原有非 Running 清队列逻辑继续覆盖暂停、胜负和重试。相机运行视口留出上下 HUD 区域，不移动实体或改变正交尺寸，退出/禁用 HUD 恢复原 rect；上下不透明面板清除视口之外的旧文字像素。
