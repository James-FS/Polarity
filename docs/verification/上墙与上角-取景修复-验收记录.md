# 上墙及上角取景修复

- 版本：2026-10-15，第一关房间 prefab、HUD prefab、Game.scene 相机。
- 原因：编辑状态相机使用全屏 rect，顶部墙体被 Overlay HUD 覆盖；Play 中 HUDView 才设置内框视口。用户截图显示的是编辑默认文字。
- 改动：相机保存为内框视口 (48,56,1184,604) / 1280×720；上墙仍10段，总宽改为26.92，端点对齐侧墙；左右上角各补0.45高侧面延续和深色金属收口；侧边HUD色调变暗，减弱素材自带亮边与场景墙的重复视觉。
- 验证：1280×720实际Play截图，上墙与四条灯带完整露出，左右上角接合；进出Play的相机视口一致，10段上墙与2个上角连接件启用。Console无日志，退出Play并保存，场景dirty=false。
- 本次纯美术/取景修改，复用既有第一关路线，不重跑完整解法。其他分辨率与后续关卡未验收。场景墙材质、磨损细节仍与概念稿有差异，本次修复重点为遮挡、位置及连接。
