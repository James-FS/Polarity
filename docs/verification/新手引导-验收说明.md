# 第一关新手引导：补充验收

2026-10-12，团结 1.10.1。以步骤 13 的 ef9068e 为基线，按用户追加要求实现；步骤 14 仍待实施。

## 已实现体验

- 每次新会话首次进入第一关显示准备卡，说明目标、WASD、左右键、极性关系、4 次初始预算、慢速与重试。整个 World 保持 Ready，Time.timeScale=0；不能移动、赋极、受伤或推进计时。开始/Enter、跳过说明/Esc 都进入正常模拟。跳过仅关闭说明卡，保留操作反馈。
- 本会话关闭卡片后，R 重试直接开始；第一关右上“查看引导”可再次打开卡片，冻结现有局面而不恢复预算、生命或位置。关闭后恢复正常运行；胜负结算不能重新打开。退出 Play 后下次会话重新显示。
- 复用原候选主体黄色轮廓，增加附近的左右键操作提示；超范围/零预算分别说明靠近/仍可移动。提示背景和文字不拦截鼠标，准备卡拦截整个屏幕。
- 使用已有 Teaching 区域显示两行短提示：无极性、同极/异极关系，以及根据实际相对速度显示靠近/分开/观察运动；超出磁力范围时明确说明。不把配置极性当成实际运动，也不规定必须先吸后斥。
- 首次赋极、改色、重复同极分别解释成本；有效标记时预算文字短暂变黄。真正 DamageCommitted 后解释撞击/尖刺/玩家接触受伤。未操作时约 2.5 模拟秒起提供一次慢速/移动提示，首次受击再提醒；提示不修改规则或强行停止游戏。
- 直接同极、正负互换、提前清场均自由结算。其他关沿用原提示，不显示准备卡、查看按钮或新悬停标签。

## 实现与资源

新增 FirstLevelTutorialView（和引擎生成 meta），修改 LevelController、SimulationWorld、HUDView 与 HUD.prefab。Controller 管理首次会话/准备请求，World 复用既有 Ready 阶段冻结唯一模拟，View 订阅已提交标记/传播/伤害并读取运动。没有改变第一关布局、配置、受力、伤害、生命或预算，也没有添加 GM 辅助、强制答案或逐步教学门槛。

Bridge 当前不提供 manage_script；调用确认 unsupported 后使用文件工具编辑 C#，通过 Bridge refresh 编译与 editor API 制作/保存 Prefab。没有编辑场景 YAML 或 Library。Prefab 的排序和空字段尾部空格由引擎序列化产生，保留引擎格式。
