三项验收全部通过，共 43 项检查。证据见[原始验收数据](./步骤8-验收.json)及[最终 Game 画面](./步骤8-最终画面.png)。实际工程为团结 1.10.1 / 2022.3.62t13，基线提交 4a0d122；沿用 Game、六敌人、负极箱子、通道和三次预算。

## 交付与操作

- 玩家初始生命 3，敌人生命 2；敌人普通接触伤玩家，但玩家普通接触不会伤敌人。箱子不可摧毁。
- 箱子撞敌人、敌人撞墙及敌人互撞，接触法向相对速度达到 4.5 时扣 1 点；低速贴靠及高速度切向滑动不判碰撞伤害。敌人受伤间隔 0.35 秒，玩家所有伤害共享 0.8 秒无敌间隔，由模拟时间计时。
- WASD、左/右键正负标记沿用原输入。R 在运行、暂停、胜利或失败时重载当前 Game，恢复完整初值与正常时间倍率。预算耗尽不判负，仍能移动与重试。
- 玩家死亡优先判负；敌人清空且玩家存活判胜。结束后 World 不再推进物理，R 输入仍由 Update 接收。调试面板显示生命、敌人数、阶段、伤害及 R 提示；正式 HUD 与视听反馈留在步骤 10—12。
- SpikeHazard 可挂到 Hazard 层的 Trigger Collider2D 上，HazardId 为正整数，记录使用负来源 ID；玩家与敌人会受伤，箱子不受伤且尖刺不传播。本次没有改变当前房间的尖刺布局，实际尖刺行为通过临时 Play 夹具验证，内容编排留在步骤 11。

新增 Health、DamageData、DamageCollection、DamageSystem、SpikeHazard、LevelController。Health 保存生命/有效性/冷却，回调仅采集数值，规则仍由 World 统一执行。Enemy Prefab 增加 Health；Player Prefab 增加 Health 与 ContactRecorder，玩家仍没有 PolarityBody。Game 增加一个 LevelController；现有刚体、碰撞体、墙体布局、磁力、移动与追击参数不变。GameplayConfig 只追加四个伤害参数，Enemy/Crate Prefab 默认仍 Neutral。

固定步顺序为：标记请求 → 步前快照 → 移动/磁力 → 一次真实 Simulate → 接触合并 → 伤害批量结算 → 排除死亡对象的传播计划与统一提交 → 统一注销/销毁 → 胜负与结果通知。每个受伤目标每步最多结算一次，双边回调和多个碰撞体不会增加次数；同一步的全部伤害先规划再提交，避免死亡处理顺序改变同时命中的结果。死亡的极性对象立即失效，不等 Destroy 完成才排除传播。敌人销毁，死亡玩家停用刚体并保留到重试。

## R 重试与保留检查

四种状态通过与键盘 Update 相同的 SampleRestartInput(true) 实际 LoadSceneAsync(Game, Single)：运行中零预算、玩家/敌人受伤与长冷却、一个待处理标记、缓存移动与 0.3 倍率；暂停且倍率 0；真实接触导致 Lost；真实触发器清空六敌人后的 Won。每种重载均恢复玩家 (5,-2.5)、七实体全部原始位置、六敌人 Neutral/生命 2、箱子 Negative、玩家生命 3、预算 3、ID 1—7、倍率 1 和 Script 模拟。新场景注册完毕后才 Running，观测在首步前暂停，以检查精确初值。

每次新场景请求、接触、传播、伤害、冷却、旧结果与完成步号均清空；第一标记序号为 1。旧 World 释放物理所有权，旧事件不响应新场景；重载中再次申请被拒，场景中只有一个 World 和一个 LevelController。零预算实际移动 20 步，向上位移 1.514；Ready/Paused 不模拟。

最终保存场景/资源，重开正常 Play 追加运行 50 步，尝试/完成均 50、失败 0、生命 3、预算 3、敌人数 6、初始极性与 ID 正确。WaitForEndOfFrame 捕获并查看 1280×720 Game 画面，生命/敌人数/Running/R 提示可读；它只证明静态界面。退出后恢复 FixedUpdate、倍率 1，Game dirty=false、Missing Script 0，Console 错误 0、警告 0。

Crate Prefab、Physics2DSettings、ProjectSettings、EditorBuildSettings 哈希不变；原 PlayerController、MarkingController、EnemyMotor、传播系统与表现排序代码保留。两角色 Prefab 仅增加组件引用和组件块。Game 仅增加 LevelController 及编辑器自动保存的玩家派生 SortingOrder=250（来自原出生 Y=-2.5），未改位置、物理和场景初始列表；美术目录及此前文档历史保留。
