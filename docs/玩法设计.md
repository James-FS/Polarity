> Game Jam 玩法设计文档  
> 主题：涌现  
> 开发周期：约 15 天  
> 文档版本：v0.3，2026-10-08  
> 状态：基础白盒、最小斜俯视表现、基础磁力、玩家移动与有限标记、受磁力影响的追击敌人已完成并验收；接触传播与完整关卡流程尚未实现，正式美术与方向动画待制作。进度见[实施步骤](./实施步骤.md)，证据见[实施记录](./实施记录.md)。

## 1. 游戏概述

《极性失控》是一款带立体感的 2D 斜俯视、单屏关卡制、以有限干预为核心的磁力实时解谜游戏。玩家没有普通攻击，每关只能少量主动标记敌人和箱子的正负极性。极性通过敌人与箱子的接触免费传播，吸引、排斥、追击和碰撞共同改变战场，玩家利用这些变化清除敌人。炮弹默认带负极，参与磁力作用，但首版不可手动标记，也不传播极性。

玩家选择传播的起点、制造相反极性的吸引目标，并保留少量改色机会进行关键干预。传播改变物体运动，运动又改变下一次接触与传播；玩家通过走位和有限的再次标记利用这个反馈，而非逐个安排所有敌人。

**一句话介绍：只有几次标记机会，让极性传播，让战场成为你的武器。**

### 1.1 核心体验

- 从看见危险，到发现危险之间可以相互利用。
- 通过少量操作启动一串可解释的变化。
- 同样的房间可以产生不同解法。
- 出现意外后，玩家能理解原因，并尝试复现或改进。

### 1.2 设计支柱

1. **共同规则：** 敌人与箱子共享极性传播规则，所有带极性的动态物体共享磁力规则。
2. **可读因果：** 玩家能看懂谁在吸引谁、为何撞击、为何失败。
3. **即时反馈：** 标记后立即生效，切换极性能明显改变局面。
4. **有限干预：** 主动标记与改色共享次数，传播免费；玩家选择起点与时机，让系统扩大影响。

## 2. 主题：涌现如何体现在玩法中

**主题的核心是“传播与运动相互反馈”，不是限制标记次数本身。** 个体的局部变化通过接触扩大，改变群体运动；新的运动又决定后续接触对象与传播路径。

```text
接触 → 传播极性 → 改变磁力与运动 → 改变下一次接触 → 改变传播
```

系统只规定个体如何传递极性、受力、追击和碰撞，不直接向群体下达“全队散开”“组成包围圈”或“进入陷阱”的指令。群体分裂、重新聚集、改变通路等整体行为，应由局部规则共同产生。

### 2.1 三条核心规则

1. 同极排斥，异极吸引；无极性物体不参与磁力。
2. 在敌人与箱子之间，带极性物体接触无极性物体，会把极性传过去；原物体保留极性。已有极性的物体不会被接触覆盖。
3. 敌人持续尝试追逐玩家，但磁力和实体碰撞会改变实际运动。

### 2.2 具体场景：一个标记改变一支队伍

六个无极性敌人在窄道中追逐玩家。玩家给其中一个标正极：

1. 它接触另一敌人，第二个敌人也获得正极。
2. 同极排斥改变两者的位置与方向。
3. 改变后的运动决定它们接下来撞到谁；有的碰撞继续传播，有的因为距离拉开而中断。
4. 后续获得极性的敌人再次改变周围运动，影响更远处的传播。
5. 玩家给箱子标负极，吸引部分正极敌人；敌人之间的排斥、追击与墙体约束仍然存在，形成新的接触与运动关系。

这里不保证所有敌人都会获得正极，也不保证形成某种固定队形。传播路径由场景、受力、追击和实际接触共同决定。玩家需要选择起点、站位与介入时机。

### 2.3 限制标记次数的作用

每关原型先给 3 次主动标记机会。首次标记和重新改色都消耗 1 次，接触传播免费。具体次数需要实测，不是不可修改的最终数值。

限制用于让玩家把传播当成扩大影响的工具，并保留机会进行关键修正。它改变的是玩家与系统的关系，本身不创造涌现。即使不限次数，反馈仍可能产生涌现；只是无限点击容易绕开传播，让玩家逐个控制局面。

### 2.4 区分机制、连锁与涌现

| 情况 | 性质 | 对主题的贡献 |
| --- | --- | --- |
| 一个敌人被异极箱子吸过去 | 基础磁力机制 | 教学作用，单独不足以表达主题 |
| 极性沿固定队列依次传递，结果总是一样 | 连锁传播 | 表现影响扩大，但缺少丰富的整体变化 |
| 传播改变运动，运动改变传播路径，队伍出现不同的分裂与聚集 | 局部规则形成反馈与整体行为 | 主要主题落点 |
| 玩家利用上述变化引导炮弹、改变通路或创造撞击工具 | 从系统行为中发现新用途 | 主题转化为可利用的玩法 |

随机混乱、对象数量多或一次点击影响很多单位，都不能单独证明主题表达成立。持续运作也不是必需条件；可解释的新整体行为与用途更重要。

### 2.5 候选战术与原型验收

优先验证：不同的传播起点能否拆散队伍、改变敌人与箱子的接触，或让敌人进入可借用的炮台火力范围。

敌人带动箱子、移动掩体和局部聚集仍是候选结果，不是保证出现的技能。不通过识别特定组合后切换到“战车模式”等方式伪造行为。

用同一个房间、相同初始位置与相同标记预算，分别改变首个标记对象或标记时机，验证是否能得到至少两种可解释、可复现、可利用的整体局面。观察不了解设计的玩家能否发现教程未直接指定的用途。

若无论标记谁，结果都是“全部染色后四散”，则只是单调的连锁效果。应先调整接触、磁力和布局，不急于扩展关卡或宣称主题已经成立。

## 3. 游戏流程与核心循环

### 3.1 单关流程

进入房间 → 观察布局与本关标记预算 → 选择传播起点并标记 → 传播、磁力与运动相互作用 → 走位并使用剩余次数关键改色 → 清除所有敌人 → 结算 → 下一关。

关卡开始前可短暂展示静止房间，玩家按确认后进入实时阶段。正式玩法保持实时，不要求每关先完成复杂布置。

### 3.2 胜负条件

- 胜利：清除本关所有活动敌人。
- 炮台为固定场景火力源，不计入清除目标，第一版不能被摧毁。
- 失败：玩家生命值归零。
- 重试：立即恢复本关初始位置、无极性/预设极性、生命、炮台计时与全部标记次数，不消耗跨关资源。
- 标记次数用完不立即判负，玩家仍可移动，等待传播和战场交互；若无法继续解决，可随时重试。
- 通关演出触发后停止危险模拟，避免清除最后一个敌人后又被残留炮弹击杀。

### 3.3 首次游玩目标

完整体验约 10—15 分钟，包含六个短关卡。单关熟练通关约 30—90 秒，具体按实测调整。失败后快速重试，减少重复阅读与等待。

## 4. 玩家操作与有限标记

| 输入 | 行为 |
| --- | --- |
| WASD | 移动 |
| 鼠标指向敌人或箱子 | 按可见外观选择候选目标，显示轮廓 |
| 左键 | 赋予正极，或把负极改为正极；有效操作消耗 1 次 |
| 右键 | 赋予负极，或把正极改为负极；有效操作消耗 1 次 |
| 按住空格 | 慢速瞄准，松开恢复正常速度 |
| R | 重试当前关卡，恢复标记预算 |
| Esc | 暂停与操作说明 |

正极显示橙色与“+”，负极显示蓝色与“−”。颜色和符号同时使用。

### 4.1 主动标记规则

- 原型默认每关 3 次标记，具体预算由关卡实测确定，不跨关累积。
- 初次标记和改成另一极性，都立即生效并消耗 1 次。
- 不支持主动清除极性。已标记物体保留极性到玩家改色或物体销毁。
- 对目标重复赋予相同极性不产生变化，也不消耗次数。
- 超出标记距离、被墙阻挡、目标不可标记或预算为零时，操作无效且不扣次数，界面提示原因。
- 标记次数在关内不会自动恢复；击杀、传播和目标销毁都不返还次数。
- 首版不另设法力、弹药或标记冷却，预算已承担有限干预的作用。
- 点击角色身体或箱子可见外观也能选中，不要求点中脚下碰撞体。候选按画面前后顺序选择最前方的可标记对象，提前显示轮廓；炮弹、阴影和纯装饰不进入候选列表。距离与墙体遮挡仍以对象脚下物理位置校验。

### 4.2 对象权限

| 对象 | 玩家主动标记 | 接触传播 | 磁力作用 |
| --- | --- | --- | --- |
| 敌人 | 可以 | 可以作为来源与接收者 | 有极性时参与 |
| 箱子 | 可以 | 可以作为来源与接收者 | 有极性时参与 |
| 炮弹 | 不可以 | 不作为来源，也不接收 | 默认负极，参与 |
| 玩家 | 不可以 | 不参与 | 不参与 |
| 固定炮台、墙、尖刺 | 不可以 | 不参与 | 不参与 |

敌人承担移动传播与群体行为，箱子承担可移动吸引/排斥中心、传播源、掩体和撞击工具。箱子并非固定锚点，受力后也会移动。

### 4.3 有限干预示例

一关八个敌人，玩家有三次机会：

1. 给一个敌人正极，尝试让它通过接触传播。
2. 给箱子负极，改变已带正极敌人的运动方向。
3. 保留最后一次，在关键时刻把箱子改成正极，推开附近正极敌人。

这是策略示例，不是每关的指定答案。如果前两步执行太晚，箱子可能已通过接触获得正极，此时改为负极仍只消耗一次。玩家需要判断何时主动介入，何时让传播完成工作。

### 4.4 玩家自身与慢速瞄准

玩家不参与磁力或极性传播，但正常与墙、箱子、敌人和炮弹碰撞。普通接触不会伤害敌人，攻击需要利用场景交互。

慢速起始倍率为正常的 30%。玩家移动、敌人移动、传播判定、炮弹与物理都按相同模拟时间减速，输入仍实时响应。慢速不返还标记，也不增加预算。

首版慢速不消耗资源；优先作为观察与瞄准辅助，不急于加入复杂能量系统。

## 5. 磁力与物理规则

### 5.1 基础关系

| A | B | 结果 |
| --- | --- | --- |
| 正极 | 正极 | 排斥 |
| 负极 | 负极 | 排斥 |
| 正极 | 负极 | 吸引 |
| 任意极性 | 无极性 | 不产生磁力 |

一对物体受到大小相等、方向相反的磁力；质量决定各自加速度。固定炮台与墙不参与磁力计算。

多个带极性的对象共同作用时，将力叠加，再限制最终加速度与速度，防止出现不可读的高速飞行。

### 5.2 接触传播

传播仅发生于敌人与箱子之间，敌人↔敌人、敌人↔箱子、箱子↔箱子使用同一规则。

| 接触前 | 接触后 | 次数消耗 |
| --- | --- | --- |
| 正极与无极性 | 两者正极 | 0 |
| 负极与无极性 | 两者负极 | 0 |
| 无极性与无极性 | 不变 | 0 |
| 两个已有极性的物体 | 各自保留原极性，不发生覆盖 | 0 |

- 需要实体接触，接近但未接触不会传播。传播不要求达到撞击伤害速度，缓慢接触也能传播。
- 来源不会丢失极性，新接收者随后可以继续传播。
- 炮弹即使接触无极性敌人，也只按命中规则处理，不传播负极。
- 主动改色后，新极性只影响此物体；它此前传播给其他物体的极性不会同步变化。
- 已有极性只能被玩家主动改色；传播无法覆盖或清除它。
- 用固定物理步长检测实际接触，包括持续接触，确保贴靠中的无极性物体也能在邻居被主动标记后接收极性。
- 同一物理步按更新前状态收集传播，再统一应用；新接收者从下一步开始成为来源，避免整个接触网络在一次遍历中瞬间染色。
- 无极性物体若同时接触正负来源，原型先按碰撞冲量较大的来源决定；冲量相同时用稳定对象顺序决定。结果须稳定，并用传播闪光显示实际来源。若此类冲突频繁且玩家难以理解，应调整布局或另行设计明确的冲突规则。
- 接触致死的物体在移除后不再参与传播，首版不保留带极性的尸体。

传播速度与近距离排斥需要一起调试。若刚传给第二个敌人就立即推远，可能切断传播；这种中断可以成为策略，但不应导致所有场景都无法形成连锁。避免初始全体紧贴、第一步便全部染色的布局。

### 5.3 游戏化模型

不追求真实电磁模拟。建议使用有限半径内的平滑力函数：

```text
若距离 d < 作用半径 R：
    力大小 = 基础强度 K × (1 − d / R)
否则：
    力大小 = 0
方向由吸引或排斥决定
```

力在近距离有上限；中心重叠时使用稳定的分离方向，避免除零与随机抖动。配合阻尼与实体碰撞处理，异极吸附不应无限加速或持续弹跳。

标记距离与磁力作用半径是两个独立参数。首版让二者接近，减少理解负担。

### 5.4 障碍与距离

首版建议：墙体阻断磁力，箱子不阻断磁力。这样墙能帮助隔离不同组合，关卡也更容易读懂。墙阻断时连线消失。

这一设定服务于玩法，需在教学中明确；若原型发现逐对遮挡计算或表现成本过高，可改为墙不阻断磁力，但必须统一规则、调整关卡并清楚提示。

### 5.5 碰撞伤害

- 箱子撞敌人、敌人撞墙、敌人相互高速碰撞，可以造成伤害。
- 伤害依据接触方向上的相对速度判断；缓慢推挤和贴靠不造成伤害。
- 碰撞后短暂限制重复受伤；持续接触不会每帧扣血。
- 炮弹撞到敌人造成直接伤害，撞到箱子或墙则销毁。
- 炮弹首版没有范围爆炸，以免扩大规则与表现成本。
- 尖刺接触敌人或玩家时造成伤害，箱子不受伤且不能销毁尖刺。
- 第一版箱子不可摧毁，避免意外失去关键玩法资源。

### 5.6 起始调参参考

以下仅用于搭建原型，不作为最终平衡标准。以敌人直径为一个距离单位。

| 参数 | 起始建议 |
| --- | --- |
| 玩家移动速度 | 敌人正常移动速度的 1.3—1.5 倍 |
| 敌人质量 | 1 |
| 箱子质量 | 3—5 |
| 炮弹质量 | 0.2—0.4 |
| 磁力半径 | 约 5—7 个敌人直径 |
| 标记距离 | 约 6—8 个敌人直径 |
| 每关主动标记预算 | 3 次，含改色，按关卡验证后调整 |
| 玩家生命 | 3 次受击 |
| 受击无敌 | 约 0.8 秒 |
| 炮台发射预警 | 约 1 秒 |
| 炮台射击间隔 | 约 3—4 秒 |

优先调整移动力、磁力、质量、阻尼和碰撞伤害阈值之间的关系，不孤立追求某个数值。

## 6. 物体与敌人

### 6.1 重箱子

初始通常无极性。可主动标记，也能通过接触获得和传播极性。质量较大，能阻挡移动与炮弹，受力后滑动。高速撞击敌人造成伤害。既是传播源、武器，也是掩体和可移动障碍。

### 6.2 追踪敌人

唯一必需的敌人类型。初始通常无极性，可主动标记，也能通过接触获得和传播极性。缓慢追逐玩家，以移动力驱动身体，磁力可以改变其方向与速度。

不要每帧直接覆盖速度或位置，否则磁力无法真正影响敌人。敌人卡住时可以调整追击方向，但不应瞬移或无条件穿越箱子。

初期房间保持简单，先用直接追击与轻量避障；只有关卡确实需要绕墙时再增加寻路。敌人会受到友方炮弹和其他敌人撞击的伤害。

### 6.3 炮台与炮弹

炮台固定，周期性瞄准玩家。预警结束后锁定方向并发射，此后炮弹不主动追踪玩家。

炮弹默认带负极，首版不可主动标记或改色，也不参与接触传播。默认负极让玩家只标记敌人就能尝试引导炮弹，减少操作负担。其特殊权限需要在首次出现时明确提示。

炮弹大、数量少、速度适中，需要留出明显偏转的时间。高速小子弹不适合这个核心玩法。

### 6.4 墙与尖刺

墙限制移动、阻挡标记与炮弹，并按首版规则阻断磁力。尖刺是明确可见的固定危险区域，提供利用排斥改变路线的机会。

## 7. 战术范例

以下是可能发现的用途，不是独立技能或指定通关步骤。所有主动赋极和改色都计入同一关卡预算。

### 7.1 选择传播起点

给队伍中一个敌人正极，观察接触如何传播、排斥如何拆开队形。前排、后排和侧翼的起点可能得到不同结果，玩家也能通过自己的位置改变追击方向与接触机会。

### 7.2 传播后吸引，再关键排斥

先用一个正极敌人传播，再给箱子负极，让附近正极敌人向箱子靠近。保留一次把箱子改成正极的机会，尝试把已靠近的敌人推向墙或尖刺。三次标记分别承担起点、引导和关键修正。

### 7.3 借用炮台

让极性传播到合适位置的敌人，使默认负极炮弹向正极目标偏转。吸引不是保证命中；距离、角度、墙体和敌人运动共同决定结果。被负极箱子吸引的正极敌人也会互相排斥，聚集形态不能预先保证。

### 7.4 敌人带动箱子

敌人与箱子异极，玩家改变站位，尝试让敌人的追击带动重物，再撞向其他单位。作为次级候选战术验证，不能用特殊状态强制实现。

### 7.5 移动传播源

带极性的箱子受力滑动，接触无极性敌人或其他箱子后传播。传出的极性可能进一步改变箱子周围的受力与运动，使传播源自身也被系统影响。

### 7.6 主动改色形成局部差异

已被传播成正极的一群敌人不会因为传播源改色而全部变负。玩家只改色其中一个，就会改变它与周围对象的关系。局部异极吸引可能带来新的碰撞，既可能有利，也可能破坏原先战术。

## 8. 关卡设计

### 8.1 原则

- 单屏固定镜头，重要关系尽量同时可见。
- 每关先突出一个新关系，再与旧关系组合。
- 保持相同初始位置与预设状态，方便通过重试比较不同起点和时机。
- 原型每关默认 3 次标记；调整预算必须基于通关测试，而不是机械套用同一个数值。
- 每关至少验证一种预算内的稳定解法，综合关卡尽量支持两种解法，并留出非像素级的操作余量。
- 主动操作太少导致只能等结果、太多导致可以逐个标记时，都需要重新调整预算或布局。
- 通关只要求清除敌人，不强制指定传播路线或队形。
- 避免“开场全员接触、立刻全染色”和“对象过于分散、始终传不出去”这两个极端。
- 耗尽次数后不能保证每种局面都可挽救；快速重试与清楚的失败原因比增加临时补给更重要。

### 8.2 六关方案

| 关卡 | 内容 | 重点 |
| --- | --- | --- |
| 1：极性 | 一个敌人、一个箱子、宽阔房间 | 主动赋极、吸引、改色排斥；三次预算的基础教学 |
| 2：接触 | 三到四个无极性敌人、箱子与侧边尖刺 | 用一次标记开始传播；观察同极排斥改变接触 |
| 3：借火 | 小群敌人、炮台、箱子掩体 | 利用传播让正极目标进入负极炮弹的作用范围 |
| 4：选择起点 | 同一房间中的两组敌人与两个箱子 | 比较不同起点与时机如何改变传播路径 |
| 5：改变通路 | 简单墙角、箱子、敌人与炮台 | 运动改变接触，接触又改变传播；保留一次关键改色 |
| 6：极性失控 | 前述对象的适量组合 | 在有限预算下创造可利用的整体局面，支持多种解法 |

前三关用简短提示明确“只能点敌人和箱子”“接触传播免费”“已有极性不会被接触覆盖”“炮弹默认负极但不传播”。第二关可先用短演示突出一次标记影响多个单位，然后重置，让玩家自行操作。

第五关依赖避障能力，若开发进度不足，用开放布局替代复杂通路。

### 8.3 结算

显示通关用时、受伤次数、主动标记使用数和本关总预算。次数限制是基础规则，不只是评分项。可选挑战是零受伤或保留一次标记，不强制特定解法，也不把复杂连锁计数作为过关条件。

## 9. 视听与界面

### 9.1 视觉方向

视觉方向确定为**带立体感的 2D 斜俯视实验室**：玩家能看见角色身体、箱子顶面与侧面、墙的立面和脚下阴影。相机保持正交并正对 XY 平面，斜俯视感由精灵绘制和遮挡产生。

正式角色暂定小型机器人，敌人为巡逻机械，箱子为金属装置。圆形敌人和方形箱子是已有白盒占位，不是最终美术要求；圆形/矩形也可继续作为脚下碰撞形状。

地面和墙使用低饱和色，正极橙色、负极蓝色突出显示。优先用有体积的简单占位验证视角，不必等完整美术资源到齐。

### 9.2 必需反馈

- 鼠标悬停显示目标轮廓，明确下一次点击会作用于谁。
- 主动标记产生脉冲，HUD 同步扣除一次机会，物体上持续显示极性符号。
- 接触传播时接收者闪光、出现符号，并用短连线与短音效标示来源；传播表现与主动标记区分，避免误以为传播也扣次数。
- 传播连锁较快时使用慢速观察辅助，不额外延迟物理判定来配合动画。
- 磁力作用使用细连线或方向提示；选中对象时优先显示相关关系，避免满屏连线。
- 高速撞击有火花、短音效和轻微震动；普通贴靠不使用相同强反馈。
- 炮台蓄力有可见方向和音效提示。
- 玩家受伤有清晰闪烁与无敌状态提示。
- 极性切换后立即体现运动趋势，不靠文字解释成功。

### 9.3 HUD

生命值、剩余敌人数、剩余主动标记次数（例如 2/3）与简短操作提示。预算为零时提示“标记已用完，仍可移动；R 重试”，不直接判负。炮弹、玩家和固定场景不显示可标记轮廓。暂停界面提供传播规则表，失败界面突出重试，通关界面突出下一关。

### 9.4 立体感、占地与遮挡

- **坐标：** 玩法继续在 XY 平面移动。X 表示左右，Y 表示地面前后；屏幕上方通常是更远的位置。Z 不用于玩法高度，也不实现跳跃、楼层或飞行。
- **脚下位置：** 每个对象有一个脚下占地锚点。移动、磁力、距离、传播和碰撞使用这个位置；图片的头部与物体立面可以在它上方延伸。
- **外观与碰撞：** 角色只在脚下占地范围发生实体碰撞，箱子使用底部占地矩形。头部/箱子上部图片重叠不等于发生碰撞或传播。选中时可显示实际占地提示，帮助理解接触。
- **前后关系：** 地面 Y 更小的对象一般画在前面，遮挡 Y 更大的对象。角色、箱子和墙体立面使用一致的排序规则。
- **阴影：** 使用贴地的半透明阴影，绑定脚下位置。阴影不参与碰撞、磁力、传播或点击选中。
- **墙体：** 墙的实体占地与上部外观分开。前景墙降低高度或必要时淡化，避免长期挡住玩家；淡化只改变画面，不改变碰撞和磁力阻挡。
- **动作：** 机器人先做四方向待机/移动的简化外观，方向只改变视觉子对象；物理根对象首版保持冻结旋转。炮台炮管可独立转向。
- **任务目标：** 当前任务仍为清除本关敌人，HUD 显示剩余数量、生命和标记机会；完成后显示通关与下一关入口，不额外扩展任务系统。

不要求精确等距菱形地图；先做易读的矩形房间和统一斜俯视素材。图片比例与碰撞范围须共同验证，不能因看起来更高就增大脚下碰撞体。

## 10. 半个月开发范围

### 10.1 必须完成

- 玩家移动、敌人/箱子标记与改色、关卡标记预算；无主动清除。
- 敌人与箱子的双向接触传播、已有极性不被覆盖、炮弹不传播。
- 有限范围磁力、阻尼、速度限制、碰撞伤害。
- 箱子、追踪敌人、固定炮台与炮弹。
- 墙、尖刺、胜负与快速重试。
- 慢速瞄准与基础视听反馈。
- 六个短关卡；若进度不足，四个打磨好的关卡优先。
- 在同一房间、相同预算下，改变起点或时机得到至少两种可解释、可复现、可利用的整体局面。

### 10.2 有余力再做

关卡选择、额外挑战、通关记录、更多音效和装饰。炮弹主动改色、固定磁性锚点等都作为后续候选，不默认纳入首版，不为它们改变当前传播规则。

### 10.3 本次不做

技能树、装备系统、随机地图、联网、复杂剧情、多种敌人免疫属性、可破坏场景、玩家自身极性、轨迹预测和自动回放。先把一种能力做深。

## 11. 建议开发安排

| 时间 | 工作 | 阶段验收 |
| --- | --- | --- |
| 第 1—2 天 | 白盒原型：玩家、六个敌人、一个箱子、简易通道；磁力、传播、三次预算 | 基础操作可读；传播和排斥会相互影响，而非全部瞬间染色 |
| 第 3—4 天 | 比较传播起点与时机，加入默认负极炮弹和炮台 | 同一布局出现两种可复现、可利用的整体局面；确认预算与传播有实际作用 |
| 第 5—7 天 | 胜负、重试、教学与前三关 | 能连续完成短流程，不需要开发者口头说明 |
| 第 8—10 天 | 综合关卡、预算验证、敌人避障与系统修正 | 每关有预算内稳定解法；综合关卡支持多解，不频繁卡死 |
| 第 11—12 天 | 斜俯视素材、前后遮挡、阴影、音效与界面 | 脚下接触可解释，人物物品有体积，极性和传播清楚 |
| 第 13 天 | 外部试玩 | 收集误解、操作困难和玩家自创打法 |
| 第 14—15 天 | 修复、删减、打包与提交 | 完整构建可从头玩到尾，符合 jam 实际提交要求 |

引擎已确定为团结 1.10.1。实际截止时间和目标平台仍需按参加的 jam 核对。

## 12. 风险、验证与处理

| 风险 | 观察信号 | 处理方向 |
| --- | --- | --- |
| 所有对象吸成一团 | 长时间无有效变化、玩家只能乱点 | 调整近距离力、碰撞分离、作用半径与空间布局 |
| 涌现不足 | 无论起点如何，都是全体染色后四散 | 验证传播与运动反馈，调整接触、磁力和布局，先不扩关 |
| 传播被主动操作替代 | 玩家逐个标记即可解决一切 | 检查预算和目标数量，让传播承担扩大影响的作用 |
| 预算过紧 | 玩家只剩等待或反复试唯一时机 | 增加操作余量、调整布局或预算，不靠随机补次数解决 |
| 传播过快或过慢 | 开场全染色，或第一跳后总被推开 | 调整初始间距、排斥、追击与接触条件 |
| 结果过于随机 | 同样操作结果差异很大，玩家无法解释 | 固定初始状态、采用固定物理步长、减少高速对象与极端力 |
| 一种打法统治所有关卡 | 玩家始终依赖同一箱子组合 | 改变布局和材料供给，让其他关系有用 |
| 敌人移动抵消磁力 | 标记后敌人仍机械地直冲玩家 | 改为受力移动，限制主动移动力 |
| 箱子总是堵死通路 | 频繁只能重试 | 增加回旋空间，确保现有极性操作能重新移动箱子 |
| 对象权限难理解 | 玩家试图标记炮弹，或以为炮弹也会传播 | 首次炮台教学明确其默认负极、不传播、不可标记，使用不同轮廓 |
| 群体交互不可读 | 看不出哪个对象导致移动 | 优先显示选中对象关系，减少同屏物体 |

### 12.1 试玩问题

1. 玩家能否解释同极排斥、异极吸引以及接触传播？
2. 玩家是否知道只能主动标记敌人和箱子，改色也消耗次数？
3. 玩家能否区分免费传播与主动标记，理解已有极性不会被接触覆盖？
4. 同一房间改变首个目标或时机后，玩家能否指出传播路径与群体运动的差异？
5. 玩家是否主动利用传播节省次数，并保留一次关键干预？
6. 玩家是否能利用整体变化引导炮弹、改变路线或制造撞击？
7. 失败时能否解释原因，并提出下一次想调整的起点、时机或站位？
8. 玩家是否发现了教程没有直接指定的用途，而不是只执行固定顺序？

### 12.2 早期止损标准

第四天结束前，若多对象作用只表现为无意义拥堵，或者无论选择何种起点与时机都只有“染色后四散”，应暂停扩关。限制次数和增加对象数量不能弥补反馈的单调。

先验证传播是否会改变运动、运动是否真正改变接触，调整磁力、追击、初始布局与预算。若仍无法得到可利用的整体差异，再决定是否收缩为磁力动作解谜，并接受其“涌现”表达较弱。

主题是否成立以原型与外部试玩为准，不以机制数量或宣传文字为准。

## 13. 待确定事项

- 引擎已确定为团结 1.10.1；目标平台待确认。
- 单人开发或团队分工。
- 采用引擎刚体，还是自定义简化二维物理。
- 传播与运动的反馈能否形成至少两种可利用的整体局面。
- 每关实际标记预算，以及三次默认预算是否足够。
- 同时接触正负来源的冲突规则是否需要简化。
- 敌人带动箱子能否形成可靠且有趣的次级组合。
- 磁力是否被墙阻断的最终选择。
- 慢速瞄准是否需要限制。
- 最终关卡数量与视觉资源预算。

## 15. v0.2 修订要点

- 将核心定位调整为有限干预的磁力实时解谜。
- 仅敌人与箱子可主动标记，且共享接触传播；炮弹默认负极，不可主动标记且不传播。
- 每关原型默认 3 次主动标记，初次赋极和改色均计次；传播免费，无主动清除，次数不自动恢复。
- 明确“传播改变运动，运动改变接触，接触改变传播”的反馈是主题核心；次数限制只突出玩家与系统的关系。
- 同步更新操作、关卡、HUD、开发安排与验收要求，所有涌现案例仍需原型验证。
