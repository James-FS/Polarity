# Codely 原生串流自动启动修复

日期：2026-10-08。团结 1.10.1；Codely Bridge 1.0.86。

## 原因

编辑器自动启动原生串流服务，但当前工作流使用 MCP/TCP，没有浏览器 DataChannel。
日志明确记录 `SendDataChannelMessage rejected: dataChannel=null`。
RPG 的历史日志也存在同类发送失败；旧版默认关闭插件日志，新版默认显示警告和错误。

## 修改

将原始 1.0.86 包复制到 `Polarity/Packages/cn.tuanjie.codely.bridge`，由编辑器包管理器解析为 Embedded。
保留包版本和原始文件，修改两个源文件：

- `Editor/Bridge/Tools/ManageWindowBridge.cs`：新增项目路径范围的自动串流开关，默认关闭；自动启动及重试检查开关；关闭菜单开关时停止服务并注销窗口变化监听。
- `Editor/Bridge/Native/NativeWindowBridgeHost.cs`：服务未运行时跳过原生 DataChannel 发送，覆盖编译进度和域重载通知。

TCP/MCP 启动逻辑、日志级别和游戏玩法未修改。
开启路径：`AI > Streaming > Auto Start Native Streaming`。
开关使用本机 EditorPrefs，按项目路径区分；其他机器默认关闭。
手动调用 `start_stream_server` 仍然可用；手动开启但没有浏览器连接时仍可能产生通道警告。
更新插件前应查看嵌入包中的 `POLARITY-PATCH.md`，保留或重新应用修复。
